# 📦 BOXINERA Importadora - Plataforma Web Oficial

Plataforma web de catálogo digital interactivo y tienda online para **BOXINERA Importadora** (Argentina).

## 🚀 Características Principales

* **Hero Banner Adaptativo Oficial:**
  * Banners oficiales en alta resolución adaptados dinámicamente para **PC (Escritorio)** y **Móviles (Celulares)** con difuminado fluido integrado.
* **Catálogo Digital Completo e Interactivo:**
  * Más de 1.900 productos (Perfumería importada, Body Splash, Gorras y Electrónica).
  * Búsqueda instantánea en tiempo real por nombre, marca o categoría.
  * Filtros por categoría, género, rango de precios y ordenamiento.
* **Sistema de Venta Mayorista y Minorista:**
  * Precios escalonados automáticos por cantidad (1 u., 3+ u., 6+ u.).
  * Barra de progreso de ahorro mayorista en el carrito.
* **Carrito de Compras y Pedidos por WhatsApp:**
  * Drawer lateral responsivo para gestionar el pedido.
  * Generación automática de mensaje detallado para WhatsApp con productos, cantidades, subtotales y total calculado para agilizar la venta directa.
* **Panel de Administración y Guía de Proyecto:**
  * Maqueta para gestión de inventario (`admin.html`) y app móvil para el dueño (`app-dueno.html`).
  * Páginas legales completas (`politica-de-privacidad.html` y `terminos-y-condiciones.html`).

## 🛠️ Tecnologías Utilizadas

* **HTML5** & **Tailwind CSS** (vía CDN optimizado)
* **Vanilla JavaScript** (sin dependencias pesadas, alta velocidad de carga)
* **Lucide Icons**
* **Base de datos:** `perfumes_db.json` / `perfumes_data.js` (preparado para integración directa con Supabase)

## 🌐 Despliegue en GitHub Pages

Este proyecto es 100% estático y puede alojarse directamente en **GitHub Pages**:
1. Ir a **Settings** > **Pages** en este repositorio.
2. En **Build and deployment > Branch**, seleccionar `main` y carpeta `/ (root)`.
3. Guardar y la web estará en vivo para compartir con clientes y el dueño de la importadora.
